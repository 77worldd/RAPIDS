# RAPIDS brand palette (locked, v4)

| Token | Hex | Role |
|---|---|---|
| `cyan-light` | `#62E4F4` | wing highlights, streaks, gradient top |
| `cyan-core`  | `#1FB9DF` | primary bird body — the brand color |
| `cyan-deep`  | `#0C7CA4` | gradient depth / hover states |
| `signal-orange` | `#F97316` | beak — accent for CTAs / highlights |
| `beak-light` | `#FBAE3C` | beak gradient light end |
| `ink-bg`     | `#17293F` | deep navy — icon tile, dark surfaces |
| `white`      | `#F4F9FC` | belly, text on ink |
| `iris`       | `#5E3A1E` | eye ring (do not reuse in UI) |

Rules:
- The bird is cyan + orange on ink. Never introduce green.
- Primary brand color = `cyan-core #1FB9DF`; use `signal-orange #F97316` sparingly.
- Dark surfaces use `ink-bg #17293F`, text on ink uses `white #F4F9FC`.
