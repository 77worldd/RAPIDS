Send media and large files straight to your download manager.

Connect RAPIDS

The first time the extension opens RAPIDS, Chrome or Edge asks whether to allow rapids:// links. Choose Always allow (or the equivalent) so later handoffs open the desktop app without the prompt. That browser permission is the connection grant.

Keep RAPIDS installed for the current user. If the app is closed, the browser starts it and the link opens the Add download sheet.

How it works

  • The extension watches completed HTTP responses for media types, media file extensions, and large files. It also scans links and media elements on demand.
  • Each tab keeps at most 200 candidates for 30 minutes. Fragments are ignored when deciding whether two links are the same.
  • A handoff is a normal rapids://add deep link with the download URL, a suggested name, the media type, the source page, and the size when known. RAPIDS always requires its own confirmation by default.
  • If a page cannot run the script (browser pages, the extension store, or a PDF viewer), the extension opens a temporary tab, lets the browser show the RAPIDS prompt, and closes the tab after a few seconds.
